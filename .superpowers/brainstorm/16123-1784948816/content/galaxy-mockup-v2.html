球体大小算法（对数缩放）

// 文件大小 1KB ~ 100GB → 球体半径 8pt ~ 80pt
func
radius(forBytes bytes: Int64) -> Float {
let minLog = log(Float(1024)) // 1 KB
let maxLog = log(Float(100_000_000_000)) // 100 GB
let valLog = log(Float(bytes))
let normalized = (valLog - minLog) / (maxLog - minLog)
return 8 + normalized * 72
}

100MB → 45pt

100GB → 80pt

数量控制策略

✅ 显示的（~30 个球）

  • 8 个分类聚合球（每个类型总大小）
  • Top 20 最大单文件球（独立显示）
  • User Home 中央太阳
  • Applications 子星系（可下钻）

❌ 不显示的

  • 50,000+ 普通文件（无法画）
  • < 1MB 的小文件（聚合到分类）
  • 已选中的待清理文件（在侧栏列表）
  • 系统隐藏文件（在 On-Demand 视图）
💡 为什么 Top 20 单文件很重要：用户最大的痛点是"哪个文件最占空间"。 这 20 个文件往往占总量 30%+，让他们一眼可见 = 直接清理动力。
