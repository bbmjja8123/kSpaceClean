# TestFlight Internal Invitation Plan — kWise v1.0

## Goal
Invite 5 internal testers across 3 channels (朋友圈, ProductHunt Coming Soon, Reddit r/macapps).

## Schedule
- T-1 month (target: 2026-09-15): 朋友圈找人 — 5 candidates from personal network
- T-2 weeks (target: 2026-10-01): ProductHunt "Coming Soon" page published
- T-1 week (target: 2026-10-08): Reddit r/macapps post linking to TestFlight

## Tester Profile Template
Each candidate must own:
- macOS 13.0+ machine (mix of Intel + Apple Silicon preferred)
- ≥ 50 GB of personal files (so scans surface non-trivial items)
- Willingness to run weekly scan + report crashes via TestFlight feedback + email

Diversity targets:
- 2 power users (creative pros — video/photo)
- 1 developer (to stress edge cases)
- 1 casual user (mother/friend, low disk literacy)
- 1 design-conscious user (to evaluate visual quality)

## Invitation Channels
1. **WeChat 朋友圈** (most personal, highest reply rate for Chinese testers)
2. **ProductHunt "Coming Soon"** (English-speaking early adopters)
3. **Reddit r/macapps** (long-tail discoverability; pin a comment with the TestFlight link once approved by mods)

## What Each Tester Gets
- TestFlight redemption link (single-use, expires in 90 days)
- Welcome doc: `kWise/docs/TestFlight/Welcome.md` (to be written — describes expected scans, how to submit feedback, how to read crash logs from `~/Library/Application Support/kWise/metric-kit/`)
- Direct email for crash escalation
