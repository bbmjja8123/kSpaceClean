プライバシーポリシー

Kraftly 製 kWatch · 最終更新日：2026-08-01

kWatch は一つの約束のもとに作られています。あなたの Mac のデータは、 常にあなたの Mac の中だけに留まること。本ポリシーでは、kWatch が 収集するデータと収集しないデータ、メニューバーに表示されるデータの 処理方法、そしてあなたが選べる選択肢について説明します。

1. 要約

kWatch は macOS メニューバー向けのアプリケーションで、リアルタイム のシステム指標（CPU、メモリ、ディスク、ネットワーク、温度、 ファン回転数、バッテリー、プロセス動作状況）を表示します。すべての 指標データは Apple の公開 API を通じて Mac から読み出され、端末 上で処理されます。kWatch はバックエンドサービスを運用せず、 テレメトリを送信せず、また「完全なディスクアクセス」を必要としません。

  • アカウント登録は不要。サインインなしで動作します。
  • リモートサーバーなし。指標データが端末外に出ることはありません。
  • 広告・トラッキングなし。広告 SDK を一切組み込みません。
  • 第三者分析サービスなし。クラッシュデータは、共有しない限り端末内に留まります。

2. 本ポリシーの対象範囲

本ポリシーは、Mac App Store で Bundle 識別子 app.kraftly.kwatch のもと配布される kWatch アプリ ケーションと、同梱されるオプションの拡張（Widget 拡張、 Live Activity、Shortcuts 連携）に適用されます。kSpaceClean、 kDupe、kFresh など Kraftly の他のアプリケーションは対象ではなく、 それぞれ独自のプライバシー文書を用意しています。

3. 収集しないデータ

kWatch は以下の情報を収集、送信、販売しません。

  • 氏名、メールアドレス、電話番号、住所。
  • Apple ID、Apple アカウントのメール、ログイン資格情報。
  • 正確な位置情報およびおおよその位置情報。
  • 連絡先、カレンダー、リマインダー、写真、メッセージ。
  • 閲覧履歴、マイクの音声、カメラ映像。
  • 健康、フィットネス、生体データ。
  • 利用状況の分析、広告識別子、アプリを横断した追跡情報。
  • メニューバーに表示されるシステム指標。

4. Mac 本体に保存されるデータ

kWatch は永続化のために macOS 標準の Application Support ディレクト リと、共有 App Group コンテナのみを利用します。書き込まれるローカル データは以下の通りです。

データ 目的 保存場所 保持期間
システム指標の履歴（CPU、メモリ、ディスク、ネットワーク） 推移グラフ表示とアラート判定 App Group Core Data ストア 7 日または 30 日（ユーザーが選択）
アラートログ 直近で発火したアラートの表示 App Group Core Data ストア 90 日
ユーザー設定（しきい値、更新間隔、テーマ） 次回起動時に構成を復元するため App Group UserDefaults 変更またはアンインストールまで
MetricKit 診断データ（クラッシュ・ハングレポート） ユーザー報告時の安定性調査 ~/Library/Application Support/kWatch/diagnostics/ 7 日、最大 10 MB

上記はいずれもあなたのユーザーアカウント内の Mac に保存され、 自動的に Kraftly や第三者に送信されることはありません。

5. kWatch が利用するシステム API

kWatch は Apple の公開 API のみを通じてシステム情報を読み取り ます。実行時に利用される API はすべて読み取り専用です。

API 読み取る内容 用途
sysctl / host_processor_info / host_statistics64 CPU 使用率、ロードアベレージ、メモリ統計、起動時間 CPU / メモリ指標カード
statfs ボリュームごとのディスク使用量と空き容量 ディスク使用量カード
getifaddrs（BSD ソケット） インターフェースごとのバイト・パケット数 ネットワークスループットカード
libproc（proc_listallpids、proc_pidinfo） プロセス名、PID、CPU / メモリ使用量（上位 N 件） 上位プロセス画面（Pro 機能）
IOKit AppleSMC CPU / GPU 温度、ファン回転数 温度 / ファン指標カード（Pro 機能）
IOKit IOAppleBattery / IOPS バッテリーサイクル数、現在容量、充電状態 バッテリー指標カード

kWatch はカーネル拡張、システムデーモン、特権ヘルパーをインストール せず、システムファイルを変更せず、ユーザーアカウント以外の場所には 一切書き込みません。

6. エンタイトルメントと権限

kWatch は App Sandbox 内で動作します。アプリはシステム指標の 読み出しに必要な最小限のエンタイトルメントのみを宣言します。

  • com.apple.security.app-sandbox — すべての Mac App Store アプリで必須。
  • com.apple.security.files.user-selected.read-only — Finder から診断レポートを開く操作を行った場合のみ使用。

kWatch は「完全なディスクアクセス」を要求しません。kWatch を 利用するために「プライバシーとセキュリティ」パネルへフォルダを 追加する必要はありません。表示される可能性がある macOS の権限 ダイアログは Apple 標準フレームワーク（通知など）に伴うもので、 拒否しても指標モニタリング機能には影響しません。

7. アプリ内購入と App Store

kWatch は一度限りの Pro アップグレードを提供します。決済は Apple が StoreKit を通じて処理し、Kraftly はクレジットカード番号や Apple アカウントのパスワードを一切把握しません。Apple は Pro エンタイトルメントを端末間で復元するために必要な取引 ID、商品 ID、購入日時のみを Kraftly に提供します。Pro エンタイトルメント は、購入の復元またはアプリの削除によっていつでも取り消せます。

v1 リリースでは Pro サブスクリプションは提供されません。将来的 にサブスクリプション価格を導入する場合は、本ポリシーを更新し、 App Store レビューガイドライン 3.1.2(a) にしたがって購入前に Paywall で自動更新の説明を表示します。

8. 診断情報とクラッシュレポート

kWatch は Apple の MetricKit フレームワークを利用して、Mac 上で クラッシュおよびハングのペイロードを記録します。MetricKit データ はローカルファイル （~/Library/Application Support/kWatch/diagnostics/） に書き込まれ、自動でアップロードされることはありません。

「設定 → 情報」内の「問題を報告」を選択すると、直近 24 時間 の MetricKit データ、現在の指標スナップショット、お使いの macOS バージョンを含む診断バンドルが作成されます。このバンドルは事前 入力された mailto: リンクに添付されるため、送信前に 内容を確認・編集できます。診断バンドルが送信されるのは、メール アプリで明示的に「送信」を押した場合に限られます。

診断バンドルには、起動中プロセスの名称や上位 N 件のアプリ名が 含まれ得ますが、ファイルの内容、Apple ID、IP アドレス、その他 の個人識別子は含まれません。

9. お問い合わせ

support@kraftly.app 宛に メールをお送りいただいた場合、Kraftly はその内容（添付ファイル および任意の診断バンドルを含む）を受領します。これらは、お客様の お問い合わせへの回答、Mac 上の kWatch に関するトラブルシュート、 製品改善のためにのみ利用し、マーケティング目的には使用しません。

10. データの保持と削除

kWatch が強制する保持期間は次のとおりです。

  • 指標履歴 — 7 日または 30 日（ユーザー選択）、経過後に完全削除。
  • アラートログ — 90 日、経過後に完全削除。
  • MetricKit 診断 — 7 日、合計サイズが 10 MB を超えると古い順に削除。
  • ユーザー設定 — 変更されるまで保持。

Finder または Launchpad から kWatch をアンインストールすると、 アプリのバイナリは削除されます。kWatch が書き込んだローカル データはお使いのユーザーライブラリに残るため、自動的には削除 されません。すべてのデータを消去するには、アンインストール前に 「設定 → 詳細 → すべてのデータをリセット」を実行するか、 アンインストール後に ~/Library/Application Support/kWatch/ フォルダと App Group コンテナ内の kWatch エントリを手動で削除 してください。

11. 第三者 SDK

kWatch は第三者 SDK、分析ライブラリ、広告ネットワーク、障害報告 サービスを一切同梱していません。すべての機能は Apple フレーム ワーク（StoreKit、MetricKit、ActivityKit、AppIntents、 CoreSpotlight、IOKit、Core Data）で実装されています。

12. お子様のプライバシー

kWatch は 13 歳以上（またはお住まいの国における同等の最低年齢） のユーザーを対象としています。kWatch は意図してお子様の個人情報を 収集しません。そもそも kWatch は誰からも個人情報を収集しないため、 特別な対応は不要です。

13. 国際的なユーザーの皆様へ

kWatch はあなたのデータを他国のサーバーへ転送しません。それは kWatch にサーバーが存在しないためです。すべての処理はあなたが 使用している端末上で行われます。本ポリシーに記載された取り扱 いは、EU 一般データ保護規則（GDPR）、カリフォルニア州消費者 プライバシー法（CCPA）、英国データ保護法、ブラジル LGPD、中華 人民共和国個人情報保護法の要件を満たすよう設計されています。

あなたの権利。現地の法令が、あなたに関する個人 データへのアクセス、削除、可搬性、異議申し立てなどの権利を 認める場合、kWatch のローカル完結設計によりそれらの権利は自動的 に充足されます。設定画面から直接行使するか、アプリをアンインスト ールすることで実現できます。

14. 本ポリシーの変更

本ポリシーに重要な変更がある場合、kWatch は次回起動時にアプリ 内の通知を表示し、上部の「最終更新日」を更新します。軽微な修正 （誤字修正、表現の明確化など）は「最終更新日」の更新のみと なります。過去の版が必要な場合は、 privacy@kraftly.app までご連絡ください。
