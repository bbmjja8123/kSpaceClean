隐私政策

kWatch 由 Kraftly 出品 · 最后更新日期：2026-08-01

kWatch 围绕一个承诺打造：你的 Mac 数据始终留在你的 Mac 上。 本政策说明了 kWatch 收集与不收集哪些数据，菜单栏中所展示数据的 处理方式，以及你可以做出的选择。

1. 概要

kWatch 是一款 macOS 菜单栏应用程序，用于展示实时系统指标 （CPU、内存、磁盘、网络、温度、转速、电池与进程活动）。所有指标 数据通过 Apple 公开 API 从你的 Mac 读取，并在本地完成处理。kWatch 不运行后端服务，不上报遥测数据，也不需要「完全磁盘访问权限」。

  • 无需注册账号。打开 kWatch 即可直接使用。
  • 无远程服务器。指标数据从不上传。
  • 无广告或追踪。kWatch 不集成任何广告 SDK。
  • 无第三方分析。崩溃数据保留在本地，除非你主动选择共享。

2. 本政策的适用范围

本政策适用于在 Mac App Store 上以 Bundle 标识符 app.kraftly.kwatch 分发的 kWatch 应用程序，以及同一 应用包内附带的可选组件（Widget 扩展、Live Activity 与 Shortcuts 集成）。本政策不适用于 Kraftly 旗下的其他应用程序，例如 kSpaceClean、kDupe 或 kFresh，它们各自维护独立的隐私文档。

3. 我们不收集的数据

kWatch 不收集、不上传、不出售以下信息：

  • 你的姓名、电子邮箱、电话号码或通信地址。
  • 你的 Apple ID、Apple 账户邮箱或任何登录凭据。
  • 你的精确位置或粗略位置。
  • 你的通讯录、日历、提醒事项、照片或信息。
  • 你的浏览历史、麦克风音频或摄像头画面。
  • 健康、健身或生物特征数据。
  • 使用分析、广告标识符或跨应用追踪信号。
  • 任何显示在菜单栏中的系统指标。

4. 存储在你 Mac 本地的数据

kWatch 仅使用 macOS 标准的 Application Support 目录与共享的 App Group 容器进行持久化存储。以下数据会写入本地：

数据 用途 存储位置 保留期限
系统指标历史（CPU、内存、磁盘、网络） 绘制趋势图表与触发告警 App Group Core Data 存储 7 天或 30 天（可在设置中切换）
告警日志 展示最近触发的告警 App Group Core Data 存储 90 天
用户偏好（阈值、刷新频率、主题） 在应用重启后恢复你的配置 App Group UserDefaults 直到你修改或卸载应用
MetricKit 诊断数据（崩溃与卡顿报告） 在你反馈问题时辅助排查 ~/Library/Application Support/kWatch/diagnostics/ 7 天，磁盘占用上限 10 MB

以上内容全部保存在你 Mac 的用户账户下，不会自动传输给 Kraftly 或任何第三方。

5. kWatch 使用的系统 API

kWatch 仅通过 Apple 公开 API 读取系统信息。运行时使用的接口均 为只读访问，列举如下：

API 读取内容 用途
sysctl / host_processor_info / host_statistics64 CPU 使用率、负载均值、内存统计、启动时间 核心 CPU 与内存指标卡片
statfs 每个卷的磁盘使用量与剩余空间 磁盘使用指标卡片
getifaddrs（BSD sockets） 每个网卡的字节与包计数 网络吞吐指标卡片
libproc（proc_listallpids、proc_pidinfo） 进程名称、PID、CPU/内存使用量（前 N 项列表） Top 进程面板（Pro 功能）
IOKit AppleSMC CPU 与 GPU 温度、风扇转速 温度与风扇指标卡片（Pro 功能）
IOKit IOAppleBattery / IOPS 电池循环次数、当前容量、充电状态 电池指标卡片

kWatch 不安装内核扩展、系统守护进程或特权辅助工具，不修改任何 系统文件，也不会写入用户账户之外的任何位置。

6. 权限与许可

kWatch 在 App Sandbox 中运行。应用仅声明读取系统指标所需的最 小权限：

  • com.apple.security.app-sandbox — 所有 Mac App Store 应用必需。
  • com.apple.security.files.user-selected.read-only — 仅在你从 Finder 打开诊断报告时使用。

kWatch 不申请「完全磁盘访问权限」。你无需在 「隐私与安全性」面板中添加任何文件夹，kWatch 即可正常使用。 你可能看到的 macOS 权限提示来自 Apple 标准框架（例如通知）， 即使拒绝也不影响指标监控。

7. 应用内购买与 App Store

kWatch 提供一次性的 Pro 升级。付款由 Apple 通过 StoreKit 处理； Kraftly 不会接触你的信用卡号或 Apple 账户密码。Apple 会向 Kraftly 提供交易标识符、产品标识符与购买日期，以便在你的设备 上恢复 Pro 权限。你可随时通过恢复购买或删除应用的方式撤销 Pro 权限。

v1 版本未提供 Pro 订阅。若未来版本引入订阅模式，本政策将相应 更新，并在 Paywall 中按 App Store 审核指南 3.1.2(a) 的要求 展示续订说明。

8. 诊断与崩溃报告

kWatch 使用 Apple 的 MetricKit 框架在你的 Mac 上记录崩溃与 卡顿数据。MetricKit 数据写入本地文件，路径为 ~/Library/Application Support/kWatch/diagnostics/， 不会自动上传。

如果你通过「设置 → 关于」中的「报告问题」发起反馈，应用会 准备一份诊断包，其中包含最近 24 小时的 MetricKit 数据、当前 指标快照以及你的 macOS 版本。该诊断包会附加到预先填好的 mailto: 链接中，便于你在发送前检查并编辑内容。 只有当你在邮件客户端中明确点击「发送」时，诊断包才会被发送。

诊断包可能包含正在运行的进程名称以及 Top N 列表中显示的 应用名称，但不会包含任何文件内容、你的 Apple ID、你的 IP 地址 或任何个人身份标识。

9. 联系客服

如果你发送邮件至 support@kraftly.app， Kraftly 将收到你的邮件内容，包括任何附件以及你选择附上的诊断 包。我们仅将该信息用于回复你的请求、协助排查你 Mac 上的 kWatch 问题以及改进产品。客服邮件不会用于市场营销。

10. 数据保留与删除

kWatch 强制执行的保留窗口如下：

  • 指标历史 — 7 天或 30 天（由你选择），到期永久删除。
  • 告警日志 — 90 天，到期永久删除。
  • MetricKit 诊断 — 7 天，总大小超过 10 MB 时清理最早记录。
  • 用户偏好 — 一直保留，直到你修改。

从 Finder 或 Launchpad 卸载 kWatch 会移除应用二进制文件。 kWatch 写入的本地数据保存在你的用户资源库中，卸载时不会自动 删除。如需清除所有 kWatch 数据，请在卸载前选择 「设置 → 高级 → 重置全部数据」，或在卸载后手动删除 ~/Library/Application Support/kWatch/ 文件夹以及 App Group 容器中的 kWatch 条目。

11. 第三方 SDK

kWatch 不捆绑任何第三方 SDK、分析库、广告网络或崩溃上报服务。 所有功能均通过 Apple 框架实现：StoreKit、MetricKit、ActivityKit、 AppIntents、CoreSpotlight、IOKit 与 Core Data。

12. 儿童隐私

kWatch 面向 13 岁及以上的用户（或你所在国家/地区规定的同等最低 年龄）。kWatch 不会明知故犯地收集儿童的个人信息。由于 kWatch 本身不收集任何人的个人信息，因此无需特殊处理。

13. 国际用户

kWatch 不会将你的数据传输至位于其他国家的服务器，因为 kWatch 不持有服务器。所有处理都在你正在使用的设备上完成。本政策中 描述的隐私实践旨在满足欧盟《通用数据保护条例》（GDPR）、 《加州消费者隐私法》（CCPA）、英国《数据保护法》、巴西 《通用数据保护法》（LGPD）以及《中华人民共和国个人信息 保护法》的要求。

你的权利。若当地法律赋予你访问、删除、可携带或 反对处理与你有关的个人数据的权利，kWatch 的本地化设计可自动 满足这些要求。你可以直接在「设置」面板中行使，或通过卸载应用 来完成。

14. 本政策的变更

若本政策发生重大变更，kWatch 将在下次启动时显示应用内通知， 并更新页面顶部的「最后更新日期」。非实质性修改（如错别字修正、 表述澄清）将仅更新「最后更新日期」。本政策的历次版本可联系 privacy@kraftly.app 获取。
