> 日期：2026-08-02
> 作者：Kraftly（用户 + Claude）

> 标杆：App Store「重复文件」分类 top 产品
> 事实来源：知识库初稿；带 `[需验证]` 的项需实测确认
> 语言：中文正文，代码/功能标识符保持英文

---

## 0. 分析结论速览

kSift 的**检测引擎**已经达到头部竞品水准（7 类检测 + APFS clone + 增量索引），但**产品化程度停留在"半成品"**：

1. **致命 UX 缺口**：无 FDA 权限引导、无 Vault 恢复入口、扫描中不可取消、图片重复不可预览 → 用户无法完成关键路径
2. **交互落后一个世代**：无拖拽、无搜索、无排序、无键盘导航、无实时扫描反馈
3. **结果页信息密度不足**：看不到图片、看不到每类占比、无法高效选择
4. **性能隐患**：`FileRowView` 每行同步读 `NSWorkspace` icon，大列表会卡 UI

> 本分析不评检测算法本身（已达标），聚焦**产品完成度**。

## 1. 现状快照（代码核实）

### 1.1 已实现能力

| 模块 | 状态 | 说明 |
|---|---|---|
| 检测 7 类 | ✅ | identical（字节 memcmp）/ directoryDedup / perceptual（dHash→Vision）/ largeFile / buildArtifact / rawJPEG + APFSCloneDetector |
| 增量索引 | ✅ | 付费解锁，Core Data 缓存 hash |
| 清理 | ✅ | Trash + Vault 双写，per-file failure 上报 |
| 历史 | ✅ | 扫描记录 + 可回看/清理 |
| 设置 | ✅ | Profile 三选、min size、perceptual toggle、build artifacts toggle、自定义目录 |
| Onboarding | ⚠️ | 3 步（欢迎 + profile + 开始），**无权限引导** |
| Paywall | ✅ | StoreKit 2，$9.99 买断，2GB 免费配额 |
| Finder Sync | ✅ | 右键"Scan with kSift"（App Group + Darwin notify） |
| App Intents | ✅ | 扫描/清理/大文件三 action |
| 本地化 | ✅ | en + zh-Hans |

### 1.2 关键缺口（代码核实）

- **Vault 无 UI**：`VaultManager` 在 `ResultViewModel` 使用，但无任何浏览/恢复界面 → 付费卖点悬空
- **无 FDA 引导**：`Info.plist` 无权限 key，Onboarding 无权限页 → 用户扫描受限却不自知
- **无取消按钮**：`ScanViewModel.cancelScan()` 存在，但 `ScanProgressView` 无 UI 调用
- **无搜索/排序**：结果页只有类别过滤 chip
- **无图片预览**：perceptual 分组只显示文件行，无缩略图
- **无拖拽**：只能通过 Profile 预设或 Finder Sync 指定目录
- **`FileRowView` 同步读 icon**：`NSWorkspace.shared.icon(forFile:)` 每行主线程调用

## 2. 竞品基线（知识库）

| 维度 | Gemini 2 (MacPaw) | Duplicate File Finder Pro | Easus DupFinder | CleanMyMac X 重复模块 |
|---|---|---|---|---|
| 定位 | 重复文件标杆，AI 相似识别 | 老牌专业去重工具 | 简单三步式 | 大套件内模块 |
| 定价 | 订阅 + Pro | 买断 `[需验证]` | 免费版 + 买断 `[需验证]` | 订阅套件 |
| 扫描范围 | 拖拽 / Finder / 全盘 | 目录选择 + 排除 | 目录选择 + 排除 | 手动选文件夹 |
| 相似识别 | 图片 + 视频 + 照片库 | 图片相似 | 图片 + 视频 | 图片 |
| 结果呈现 | 分组 + 缩略图对比 | 双栏（组→文件） | 列表 | 分组列表 |
| 智能选择 | Smart Selection（保留最常用/最新） | 按日期/路径策略自动选 | 保留最新 | 保留最新 |
| 清理 | 移到废纸篓 + 恢复 | 废纸篓 | 废纸篓/永久 | 移到废纸篓 |
| 关键体验 | 图片重复一目了然 | 过滤/排序/预览强 | 简单 | 与系统清理整合 |

### 竞品共同特征（kSift 全部缺失或部分缺失）

1. **扫描前明确选目录**（拖拽 / 目录列表 / 排除项）
2. **图片/视频相似组可预览对比**
3. **结果可搜索、可排序、可过滤**
4. **组内文件选择策略可选**（最新/最旧/路径）
5. **清理后可恢复**（废纸篓 + 专用恢复界面）
6. **键盘导航 + 快捷键**
7. **扫描实时反馈**（当前目录、已发现数量）

## 5. 建议实施顺序

```
Phase A（P0 核心闭环，~40h）：
  P0-1 FDA 引导 → P0-2 Vault UI → P0-9 范围预览 → P0-5 拖拽 → P0-6 实时反馈+取消
  → 关键路径打通：授权 → 选目录 → 扫描可中断 → 清理可恢复

Phase B（P0 结果页质量，~25h）：
  P0-3 缩略图 → P0-8 排序 → P0-4 搜索 → P0-7 icon 异步 → P0-10 空态

Phase C（P1，~52h）：按依赖依次
Phase D（P2）：长期
```

## 6. 风险与注意事项

1. **P0-3 缩略图预览**依赖感知检测结果质量；若相似阈值过宽会产生误报组，预览反而放大问题 → 需先抽样验证 dHash 阈值
2. **P0-2 Vault UI** 涉及文件系统写操作，恢复失败必须可重试且有提示
3. **P0-1 FDA** 引导文案需符合 App Review 审核（不得承诺扫描系统文件能力）
4. 所有 UI 改动需同步更新 en/zh-Hans `Localizable.strings`
5. 每项 P0 完成即跑 `swift test`（现 94 通过 + 1 预存失败 `testRemoveSelectedSurfacesFailuresAndKeepsGroup` 待修）

## 7. 验收标准

- [ ] 新用户首启可在 3 步内完成授权并开始扫描
- [ ] 扫描中可随时取消；取消后回到 idle 且无残留状态
- [ ] 图片重复组直接看到缩略图对比，无需进组逐行看
- [ ] 结果页可按文件名搜索、按大小/日期排序
- [ ] 清理后可在 Vault 恢复；Vault 过期条目自动清理
- [ ] 扫描 10k+ 组结果页滚动不掉帧（≥50fps）
- [ ] en/zh-Hans 双语截图均可用于 App Store 商店页
