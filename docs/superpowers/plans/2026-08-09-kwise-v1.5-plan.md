## Architecture

1. **UI shell (Hybrid)** — `RootView` 重构为 `NavigationSplitView`：左侧窄栏 (Smart Care / Privacy / Disk Health / Settings)；右侧大区显示当前模块。**首屏**：单个 hero CTA "Smart Care" + 3 个小模块卡 (Privacy / Disk Health / Settings)。
2. **M1 Smart Care** — 新模块 `Features/SmartCare/`，封装 ScanResultsView / CleanupContentView / CleanupEngine 的"一键"入口，提供 hero CTA 触发；3 步 orchestrator (scan → recommended-pick → confirm)。
3. **M3 隐私清理** — 现有 `Features/PrivacyClean/` 路由接通 + 新增 `Features/PrivacyClean/TCCOverview/` (inline minimal PrivacyShield)。
4. **M4 磁盘健康** — 新模块 `Features/DiskHealth/`，含 `DiskHealthCard` (首屏小卡) + `DiskHealthDetailView` (点击进详情)；SMART 读取 + 卷诊断；Apple Silicon graceful fallback。
5. **精品信号分布** —
   - C-1 (友好条目): PrivacyScanner / ScanResults / DiskHealth 全部 surface
   - C-3 (即时反馈): CleanupEngine.postCleanup hook
   - C-4 (可逆): TrashMover 30-day rollback
   - C-5 (FDA 边界): TCCOverview + DiskHealth 双卡都做引导
   - C-6 (反恐营销): 文案 grep 卡
   - C-8 (菜单栏): MenuBarManager 实时数字 ≤10s refresh

## Tech Stack

- Swift 5.9, macOS 13.0+ minimum (compile target 14 SDK), SwiftUI
- kFoundation/Sources/{DesignSystem, Capabilities, CommonUtils} — 已就位
- TCC.db 读取：`import SQLite3` (Apple built-in)
- S.M.A.R.T. 读取：`diskutil info` via `Process` subprocess (FDA-required)
- Core Data + Codable (沿用现有 Persistence 层)

## Open Risks

1. **TCC.db schema 变化** — Apple 不公开 schema，靠逆向。已通过 graceful fallback (Q8 B 兜底) + 单测回归缓解。
2. **diskutil subprocess 在沙箱内** — 需要 FDA，spec 已要求 (CLAUDE.md §2.4)。如审核被拒 → 退回 graceful "unavailable" 文案。
3. **macOS 13 vs 14 TCC 行为差异** — `import SQLite3` 在两版一致；view 层用 #available 隔离 macOS 14+ features (interactive widget 等)。
4. **App Store 审核对清理类应用态度** — Apple 历史上收紧，但 DaisyDisk 持续通过 + C-5/C-6 信号已对齐"实用工具"叙事。
5. **Co-Authored-By trailer 规范化** — 后续 merge 到 main 时建议 scripts/merge-app 自动 strip（如尚未实现，需补一个 commit）。
