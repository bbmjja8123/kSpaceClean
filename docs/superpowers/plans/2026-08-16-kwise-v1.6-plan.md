## Architecture

1. **Interactive Widget (macOS 14+)** — replace `kWise/Widgets/kWiseWidget.swift`'s `StaticConfiguration` with `AppIntentConfiguration` (gated by `#available(macOS 14.0, *)` for backwards compatibility). Single hero CTA "Smart Care" backed by a new `SmartCareIntent: AppIntent` that, when invoked, raises the main window and dispatches a notification to `SmartCareOrchestrator.runSmartCare()`. The widget also reads a small `WidgetSnapshot` (current disk usage + "上次清理时间") for at-a-glance display.

2. **Live Activity hook (macOS 14+)** — when `SmartCareOrchestrator` transitions to `.cleaning(progress)`, start a `CleanupActivityAttributes` activity. Update progress every ~500ms via the actor's poll. When state transitions to `.done` or `.failed`, end the activity after a 2-second linger so the user can read the final freed-bytes value.

3. **Cross-cutting bridge** — a new `SmartCareWidgetBridge` singleton (in `Features/SmartCare/`) that both `SmartCareOrchestrator` and the widget extension can read/write. Keeps the widget gallery in sync with the home card without coupling the extension to the main app's process state.

## Tech Stack

- Swift 5.9, macOS 13.0+ minimum (compile target 14 SDK).
- WidgetKit + AppIntents + ActivityKit (macOS 14+ only, gated).
- Existing `CleanupActivityAttributes` reused — no new shared types.
- pbxproj hand-edited per file (the `generate_project.py` is still kSpaceClean-hardcoded).

## Open Risks

1. **Widget extension target** — kWise.xcodeproj does not currently have a separate Widget Extension target. Creating one requires pbxproj work for the new target (PBXNativeTarget + PBXCopyFilesBuildPhase + WidgetKit.framework embed). Plan accepts the extra pbxproj complexity in Task W2.
2. **Live Activity requires Info.plist `NSSupportsLiveActivities = true`** — must be added to the main app target's Info.plist. Task L1 includes this edit.
3. **App Group sandboxing** — the bridge singleton lives in the main app's process; the widget extension reads/writes via App Group UserDefaults. The App Group entitlement must be added to both targets.
