# kWatch v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build kWatch v1, a sandboxed macOS 13+ menu-bar system monitor with a generous free tier, a $7.99 Pro buyout, native widgets/platform integrations, and zero analytics or network reporting.

**Architecture:** A Swift Package named `kFoundation` owns platform-neutral metric models, monitor protocols, sampling, and shared utilities. The kWatch app uses Clean Architecture with protocol-based dependency injection: platform adapters feed an actor-based metrics aggregator, repositories persist history and preferences, and SwiftUI/AppKit presentation layers consume immutable snapshots. The app writes an atomic read-only JSON snapshot to an App Group container for WidgetKit and Live Activity consumers; those extensions never open the app's Core Data store.

**Tech Stack:** Swift 5.9+, SwiftUI, AppKit, WidgetKit, ActivityKit where available, App Intents, Core Data, StoreKit 2, MetricKit, IOKit/libproc/sysctl/statfs/getifaddrs, XCTest, XCUITest, macOS 13 deployment target, macOS 14 SDK.

## Global Constraints

- Minimum OS is **macOS 13.0**; every macOS 14-only API must be guarded with `#available` and have a useful macOS 13 fallback.
- Build against the macOS 14 SDK with Swift 5.9+ and `SWIFT_STRICT_CONCURRENCY = complete`.
- All targets use App Sandbox; kWatch requests no TCC permission and performs read-only monitoring only.
- Do not use privileged helpers, SMJobBless, undocumented private APIs, or network telemetry.
- SMC access is optional and must degrade to an explicit unsupported state; temperature/fan data must never be fabricated.
- The app, Widget, Live Activity, and Intents share only the App Group snapshot and UserDefaults suite; extensions do not access Core Data.
- Free users retain CPU, memory, disk, network, three menu-bar display modes, basic Widget, Spotlight lookup, and basic Shortcuts.
- Pro is a non-consumable StoreKit 2 purchase: $7.99 US reference price, with regional prices configured in App Store Connect.
- Public APIs in `kFoundation` require DocC comments; tests must cover the core logic and the final test run must include `swift test` plus app/unit/UI checks.
- Localize user-visible strings in English, Simplified Chinese, and Japanese; do not hard-code copy in views.
- Never copy Objective-C/C++ implementation from Lemon. Lemon is a behavior reference only.

public enum MetricKind: String, CaseIterable, Codable, Sendable {
    case cpu, memory, disk, network, temperature, fan, battery
}

public enum MetricValue: Codable, Equatable, Sendable {
    case percentage(Double)
    case bytes(UInt64)
    case bytesPerSecond(UInt64)
    case degreesCelsius(Double)
    case revolutionsPerMinute(Double)
    case volts(Double)
    case text(String)
    case unavailable(MetricError)
}

public enum MetricAvailability: Codable, Equatable, Sendable {
    case available
    case unsupported(reason: String)
    case unavailable(reason: String)
}

public struct MetricSample: Codable, Equatable, Sendable {
    public let kind: MetricKind
    public let value: MetricValue
    public let availability: MetricAvailability
    public let timestamp: Date
}

public struct MetricSnapshot: Codable, Equatable, Sendable {
    public let timestamp: Date
    public let values: [MetricKind: MetricValue]
    public let availability: [MetricKind: MetricAvailability]

    public init(timestamp: Date, values: [MetricKind: MetricValue], availability: [MetricKind: MetricAvailability] = [:]) {
        self.timestamp = timestamp
        self.values = values
        self.availability = availability
    }
}

public enum MetricError: Error, Codable, Equatable, Sendable {
    case unsupported(String)
    case systemCall(String, Int32)
    case malformedData(String)
}

public protocol MetricMonitor: Sendable {
    var kind: MetricKind { get }

}

public struct SamplingStrategy: Sendable, Equatable {
    public let interval: Duration
    public let historyInterval: Duration
    public init(interval: Duration = .seconds(2), historyInterval: Duration = .seconds(30)) {
        self.interval = interval
        self.historyInterval = historyInterval
    }
}

public protocol KWatchClock: Sendable {
    func now() -> Date
}

public struct SystemClock: KWatchClock {
    public init() {}
    public func now() -> Date { Date() }
}

```swift
public actor MetricsAggregator {
    private let monitors: [any MetricMonitor]
    private let strategy: SamplingStrategy
    private var continuations: [UUID: AsyncStream<MetricSnapshot>.Continuation] = [:]
    private var task: Task<Void, Never>?

    public init(monitors: [any MetricMonitor], strategy: SamplingStrategy = .init()) {
        self.monitors = monitors
        self.strategy = strategy
    }

    public func stream() -> AsyncStream<MetricSnapshot> {
        let id = UUID()
        return AsyncStream(bufferingPolicy: .bufferingNewest(1)) { continuation in
            continuations[id] = continuation
            continuation.onTermination = { [weak self] _ in
                Task { await self?.remove(id) }
            }
        }
    }

    public func start() {
        guard task == nil else { return }
        task = Task { [weak self] in
            while !Task.isCancelled {
                await self?.sampleOnce()
                try? await Task.sleep(for: strategy.interval)
            }
        }
    }

    public func stop() {
        task?.cancel()
        task = nil
        continuations.values.forEach { $0.finish() }
        continuations.removeAll()
    }

    private func sampleOnce() async {
        var values: [MetricKind: MetricValue] = [:]
        var availability: [MetricKind: MetricAvailability] = [:]
        await withTaskGroup(of: MetricSample?.self) { group in
            for monitor in monitors {
                group.addTask {
                    do { return try await monitor.sample() }
                    catch { return MetricSample(kind: monitor.kind, value: .unavailable(.systemCall(String(describing: error), 0)), availability: .unavailable(reason: String(describing: error)), timestamp: Date()) }
                }
            }
            for await sample in group {
                guard let sample else { continue }
                values[sample.kind] = sample.value
                availability[sample.kind] = sample.availability
            }
        }
        let snapshot = MetricSnapshot(timestamp: Date(), values: values, availability: availability)
        continuations.values.forEach { $0.yield(snapshot) }
    }

    private func remove(_ id: UUID) { continuations.removeValue(forKey: id) }
}
```

Use an injected clock in the production version so timestamps are deterministic in tests; the snippet shows the required actor boundaries and buffering behavior.

```swift
public struct CPUStats: Sendable, Equatable { public let user, system, idle: UInt64 }
public protocol CPUStatsProvider: Sendable { func read() throws -> CPUStats }
```

`CPUMonitor.sample()` consumes two consecutive stats; first sample returns 0%; subsequent samples use `(totalDelta - idleDelta) / totalDelta * 100`, clamped to 0–100. `MemoryMonitor` divides `activeBytes` by `totalBytes`, clamping to 0–100 and returning 0 when total is 0.

`HostCPUStatsProvider` uses `host_processor_info` with `PROCESSOR_CPU_LOAD_INFO`, sums USER/NICE into `user`, SYSTEM into `system`, IDLE into `idle`, then `vm_deallocate`s the buffer with size `MemoryLayout<integer_t>.stride * processorMsgCount` (the kernel allocates one `integer_t` per tick, not a `processor_info` struct). Wrap the file in `#if canImport(Darwin)`.

`HostMemoryStatsProvider` uses `host_statistics64` with `HOST_VM_INFO64`, multiplies `active_count + wire_count + compressor_page_count` by `vm_kernel_page_size`, and reports against `ProcessInfo.processInfo.physicalMemory`. Wrap in `#if canImport(Darwin)`.
