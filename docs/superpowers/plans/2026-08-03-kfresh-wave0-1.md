# kFresh Wave 0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the deferred-work backlog from the Wave 0 final whole-branch review (10 findings) and the Wave 1.1 final-review recommendations (plan-text hygiene), via a single sequenced wave that finishes on `main` as ONE squash commit — honoring the user's standing "全部完成再提交" directive while preserving per-task review gates on a local feature branch.

**Architecture:** Wave 0.1 is the final close-out of the kFresh v1 codebase before feature freeze. Four tasks: (0) commit the never-merged `kUninstall/` → `kFresh/` directory rename as a single `chore` commit on the temp branch so git rename-detection can pair the 70 deleted paths with their 70 already-committed `kFresh/` counterparts; (1) one-line `fix` for the CaskParser slack→bundle-ID map (M1/I-3); (2) a docs commit that updates `.superpowers/sdd/progress-kfresh-wave0.md` to mark all 10 Wave-0-deferred findings with their final disposition, plus a reword of 4 stale plan-text acceptance items in the Wave 1.1 plan (final-review recommendation #3); (3) nothing — covered by Task 2. After per-task review gates pass, a final whole-branch review (opus) over `1fbac77..temp-branch-HEAD` validates the temp branch, then `git merge --squash kFresh/wave0-1` collapses the wave's N commits into one on `main`.

**Tech Stack:** Swift 5.9+, Xcode project generated by `kFresh/generate_project.py` (source of truth), git rename-detection, squash merge.
